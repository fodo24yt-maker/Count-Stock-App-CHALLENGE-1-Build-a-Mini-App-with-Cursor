The task was:
CHALLENGE 1: Build a Mini App with Cursor

Level: Beginner

Build a small working app from scratch with Cursor scaffolding and debugging alongside you. Always check cursor.com/docs for the latest.
What are we building?

Something small but real — a to-do list, a tip calculator, a weather lookup. You’ll go from a blank file to a running app, with Cursor writing boilerplate and helping you fix errors as they pop up. The goal is to feel how fast you can move with an AI pair.
How it works

    Go to cursor.com and click Download (it auto-detects your OS).
    Pick a tiny idea — keep the scope small so you can finish.
    Let Cursor scaffold it — describe the app and let the AI generate the starting code.
    Iterate and debug — run it, hit an error, ask Cursor to fix it, repeat.

Steps

    Open the Cursor Desktop App and select New Chat.
    In the dropdown menu above the chat window, select New Folder to create a new project folder.
        Optional: Open an existing project folder from the dropdown menu.
        Recommended: Open the IDE and open the side chat for a new agent.
    Describe your app, e.g., “Build a simple tip calculator as a single HTML page with a little JavaScript.”
    Let Cursor generate the files. Run it (open the HTML file in your browser, or run the script).
    Hit a bug or want a change? Ask Cursor: “The total isn’t updating when I change the tip percent — fix it” or “Add a dark mode toggle.”
    Repeat until it works the way you want.
